# Git 워크플로 (HOW)

작업: **커밋/브랜치**를 다룰 때 참조.

- **현재 상태**: 원격 `origin` = `https://github.com/detaimer/NOIR.git`, 기본 브랜치 `main`. 커밋은 **사용자가 요청할 때만** 수행한다.
- **브랜치**: 기본 브랜치에서 직접 작업하지 말고 기능 브랜치(`feat/…`, `fix/…`, `docs/…`)에서.
- **커밋 메시지**: 명령형 요약 1줄 + 필요 시 본문(무엇을/왜).
- **Attribution**: 세션에서 지정된 co-author / 세션 링크 트레일러를 커밋 말미에 붙인다.
- **금지**: 사용자 요청 없이 push/커밋, 외부로의 산출물 전송.
